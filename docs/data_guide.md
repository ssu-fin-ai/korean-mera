## 1. 데이터 수집 구조

| 데이터 | 소스 | 과거 호환 | 캐시 단위 |
|--------|------|-----------|-----------|
| OHLCV | pykrx → FDR fallback | ✅ | 날짜 범위별 parquet |
| PER/PBR/EPS/BPS/DIV/DPS | pykrx (KRX 로그인) | ✅ | 월별 JSON |
| DART 재무제표 | OpenDartReader | ✅ (연도 자동 선택) | 월별 JSON |
| 공매도 비중 | pykrx | ✅ | 날짜별 JSON |
| 섹터 정보 | FinanceDataReader | ✅ | 7일 parquet |
| 유사 패턴 검색 | ChromaDB (OpenAI 임베딩) | ✅ | 영구 벡터 DB |

> **DART 연도 자동 선택**: 사업보고서 제출 기한(3월 31일) 기준.
> 4월 이후 → 전년도, 1~3월 → 전전년도 사업보고서 사용.

## 2. 기술적 지표

### 2-1. 수익률 지표

| 지표 | 계산 | 해석 |
|------|------|------|
| `ret_1d` | 전일 대비 등락률 | 당일 모멘텀 |
| `ret_5d` | 5거래일(1주) 수익률 | 단기 추세 방향 |
| `ret_20d` | 20거래일(1개월) 수익률 | 중기 추세 강도 |
| `ret_60d` | 60거래일(3개월) 수익률 | 중장기 모멘텀 |
| `returns_series` | 최근 20일 일별 수익률 배열 | 패턴 유사도 임베딩 핵심 |

### 2-2. 추세 지표

| 지표 | 계산 | 해석 |
|------|------|------|
| `close_to_ma20` | (현재가 / MA20) - 1 | +5% 이상: 단기 과열 / -5% 이하: 단기 침체 |
| `close_to_ma60` | (현재가 / MA60) - 1 | 중기 추세 위치 판단 기준 |
| `macd_diff` | MACD - Signal Line | > 0: 골든크로스 / < 0: 데드크로스 |
| `adx` | Average Directional Index (14일) | 25 이상: 추세 존재 / 25 미만: 횡보 |

### 2-3. 모멘텀 지표

| 지표 | 계산 | 해석 |
|------|------|------|
| `rsi` | Relative Strength Index (14일) | 70 이상: 과매수 / 30 이하: 과매도 |
| `stoch_k`, `stoch_d` | Stochastic (14일) | 80 이상 / 20 이하가 신호 기준 |
| `cci` | Commodity Channel Index | ±100 초과 시 강한 추세 신호 |
| `williams_r` | Williams %R | -20 이상: 과매수 / -80 이하: 과매도 |

### 2-4. 변동성 지표

| 지표 | 계산 | 해석 |
|------|------|------|
| `bb_pct` | (현재가 - BB하단) / (BB상단 - BB하단) | 0.9 이상: 상단 돌파 / 0.1 이하: 하단 접근 |
| `bb_width` | (BB상단 - BB하단) / BB중간 | 클수록 변동성 확대 국면 |
| `atr` | Average True Range (14일) | 절대 변동폭. 손절선 설정에 활용 |
| `hist_vol_20` | 20일 일별 수익률 표준편차 × √252 | 연환산 역사적 변동성 |

### 2-5. 거래량 지표

| 지표 | 계산 | 해석 |
|------|------|------|
| `volume_ratio` | 당일 거래량 / 20일 평균 거래량 | 2 이상: 급증 / 0.5 이하: 급감 |
| `obv` | On-Balance Volume | 추세 방향과 거래량의 일치 여부 |
| `mfi` | Money Flow Index (14일) | RSI의 거래량 가중 버전. 80/20이 기준 |
| `vwap` | 거래대금 / 거래량 | 당일 평균 매매 단가 (기관 기준가 추정) |

### 2-6. 상대강도 지표

| 지표 | 계산 | 해석 |
|------|------|------|
| `rel_strength_5d` | 종목 5일 수익률 - KOSPI 5일 수익률 | 양수: 시장 대비 강세 |
| `rel_strength_20d` | 종목 20일 수익률 - KOSPI 20일 수익률 | 섹터 순환 판단에 활용 |
| `beta_20d` | 종목/KOSPI 공분산 / KOSPI 분산 (20일) | 1 초과: 시장보다 변동성 큼 |

## 3. 기본적(재무) 지표

### 3-1. 밸류에이션 지표

| 지표 | 계산 | 해석 | 출처 |
|------|------|------|------|
| `per` | 주가 / EPS | 낮을수록 저평가. 섹터 평균과 비교 필수 | pykrx |
| `pbr` | 주가 / BPS | 1 미만: 청산가치 이하. 가치주 핵심 지표 | pykrx |
| `eps` | 당기순이익 / 발행주식수 | 수익력 측정. 전년 대비 성장률이 핵심 | pykrx |
| `bps` | 자기자본 / 발행주식수 | 주당 순자산. 안전마진 판단 기준 | pykrx |
| `graham_number` | √(22.5 × EPS × BPS) | Graham의 적정주가. 현재가 < Graham Number = 저평가 | 계산 |
| `per_vs_sector` | 종목 PER / 섹터 중앙 PER - 1 | +20%: 섹터 대비 20% 비쌈 | 계산 |
| `pbr_vs_sector` | 종목 PBR / 섹터 중앙 PBR - 1 | 음수: 섹터 평균보다 저평가 | 계산 |

### 3-2. 수익성 지표

| 지표 | 계산 | 해석 | 출처 |
|------|------|------|------|
| `roe` | 당기순이익 / 자기자본 × 100 | 15% 이상: 우수. Buffett 기준선 | DART (EPS/BPS 근사) |
| `roa` | 당기순이익 / 총자산 × 100 | 자산 활용 효율. 5% 이상이면 양호 | DART |
| `revenue` | 매출액 (원 단위) | 성장주 판단의 핵심 | DART |
| `op_income` | 영업이익 | 본업 수익력. 영업이익률 = op_income/revenue | DART |
| `net_income` | 당기순이익 | 최종 이익. 비경상적 항목 포함 | DART |
| `revenue_yoy` | (당기 매출 - 전기 매출) / \|전기 매출\| × 100 | 양수: 성장 / 음수: 역성장 | DART 파생 |
| `op_income_yoy` | 영업이익 전년 대비 성장률 | 이익 레버리지 판단 | DART 파생 |
| `net_income_yoy` | 순이익 전년 대비 성장률 | 실질 이익 개선 확인 | DART 파생 |

### 3-3. 안정성 지표

| 지표 | 계산 | 해석 | 출처 |
|------|------|------|------|
| `debt_ratio` | 총부채 / 자기자본 × 100 | 100% 이하: 안정. 200% 초과: 과부채 위험 | DART |
| `current_ratio` | 유동자산 / 유동부채 × 100 | 200% 이상: 단기 유동성 우수 | DART |
| `interest_coverage` | 영업이익 / 이자비용 | 1.5 미만: 위험. 3 이상: 안전 | DART |

### 3-4. 배당 지표

| 지표 | 계산 | 해석 | 출처 |
|------|------|------|------|
| `div` | 배당수익률 (%) | 시가배당률. 국채 금리 대비 매력도 판단 | pykrx |
| `dps` | 주당배당금 (원) | 절대 배당 크기 | pykrx |
| `payout_ratio` | DPS / EPS × 100 | 30~60%: 적정. 100% 초과: 지속 불가 | 계산 |
| `fcf` | 영업활동현금흐름 - CAPEX | 실질 자유현금흐름. 배당 지속 가능성 판단 | DART |
| `ocf` | 영업활동현금흐름 | FCF 미산출 시 대체 지표 | DART |

## 4. 시장 데이터

| 지표 | 계산 | 해석 | 출처 |
|------|------|------|------|
| `current_price` | 분석 기준일 종가 | 절대 가격 수준 | OHLCV |
| `mktcap` | 시가총액 (원) | 대형주/중소형주 구분. 유동성 판단 | OHLCV (pykrx) |
| `pct_from_52w_high` | (현재가 / 52주 고가) - 1 | -20% 이하: 조정 구간. 테마주 사이클 판단 | OHLCV 계산 |
| `pct_from_52w_low` | (현재가 / 52주 저가) - 1 | +10% 이하: 바닥권. 위기종목 반등 가능성 판단 | OHLCV 계산 |

> 52주 데이터를 위해 OHLCV 조회 기간은 380일(약 271 거래일)로 설정.

| `sector_pbr_median` | 동일 섹터 종목 PBR 중앙값 | 섹터 자산 가치 기준선 | 캐시 집계 |

## 8. 전문가별 데이터 매핑

### 성장주 전문가 (growth)

**역할**: 고PER·실적 모멘텀 종목의 BUY/HOLD/SELL 판단

| 데이터 | 사용 목적 |
|--------|-----------|
| `revenue_yoy`, `op_income_yoy`, `net_income_yoy` | 실적 모멘텀 확인 (핵심) |
| `eps` | 수익력 절대 수준 |
| `rsi`, `macd_diff`, `ret_5d`, `ret_20d` | 주가 모멘텀 방향 |
| `volume_ratio`, `obv`, `mfi` | 거래량 동반 여부 |
| `rel_strength_5d`, `rel_strength_20d` | 시장 대비 초과 수익 확인 |
| `sector` | AI·반도체·2차전지 등 성장 섹터 여부 |
| `short_ratio` | 숏 포지션이 크면 역설적 반등 가능 |
| 유사 과거 패턴 | 유사 모멘텀 국면의 이후 수익률 |

**판단 기준**: `op_income_yoy > 20%` + `rsi 50~70` + `volume_ratio > 1.5` = 강한 BUY 신호

---

### 가치주 전문가 (value)

**역할**: 저PBR·자산가치 기반 저평가 종목 발굴

| 데이터 | 사용 목적 |
|--------|-----------|
| `pbr`, `per` | 절대 저평가 수준 |
| `pbr_vs_sector`, `per_vs_sector` | 섹터 대비 상대 저평가 여부 |
| `graham_number` | Graham 적정가 대비 현재가 위치 |
| `roe`, `roa` | 자산/자본 활용 효율 |
| `debt_ratio` | 부채 과다 여부 (저PBR 함정 판단) |
| `current_ratio` | 단기 유동성 안전마진 |
| `interest_coverage` | 이자 부담 감당 능력 |
| `div`, `dps`, `payout_ratio` | 주주환원 수준 |
| `fcf` | 배당·자사주 매입 지속 가능성 |
| `pct_from_52w_low` | 기술적 바닥권 여부 |

**판단 기준**: `pbr < 1` + `roe > 8%` + `debt_ratio < 100%` + `per_vs_sector < -20%` = 가치 매수 시점

---

### 테마주 전문가 (theme)

**역할**: 정책·이슈 모멘텀 기반 단기 급등 종목 판단

| 데이터 | 사용 목적 |
|--------|-----------|
| `volume_ratio` | 거래량 폭발(테마 진입 신호) |
| `rsi` | 70 이상: 과열 → 익절 검토 |
| `bb_pct` | 상단 돌파 여부 |
| `ret_5d`, `ret_20d` | 단기 급등 강도 |
| `pct_from_52w_high` | 신고가 갱신 여부 |
| `short_ratio` | 공매도 집중 = 테마 고점 경고 |
| DART 공시 | 정책수혜·계약 발표 등 테마 원인 파악 |
| 유사 과거 패턴 | 유사 급등 국면의 이후 조정 패턴 |

**판단 기준**: `volume_ratio > 3` + `rsi < 70` + 공시 확인 = 테마 초기 진입 가능

---

### 배당주 전문가 (dividend)

**역할**: 고배당·방어적 섹터의 안정 수익 판단

| 데이터 | 사용 목적 |
|--------|-----------|
| `div` | 배당수익률 (채권 대비 매력도) |
| `dps` | 절대 배당 크기 |
| `payout_ratio` | 배당 지속 가능성 1차 판단 |
| `fcf`, `ocf` | 실질 현금 창출력 = 배당 지속 가능성 2차 판단 |
| `roe`, `roa` | 수익성 안정성 |
| `debt_ratio`, `interest_coverage` | 재무 건전성 |
| `hist_vol_20` | 변동성 낮을수록 방어주 성격 |
| `beta_20d` | 1 미만: 시장 하락 시 방어적 |
| `rel_strength_20d` | 하락장에서 상대적 강세 여부 |

**판단 기준**: `div > 3%` + `payout_ratio < 70%` + `fcf > 0` + `debt_ratio < 100%` = 안정적 배당주

---

### 위기종목 전문가 (crisis)

**역할**: 급락 종목의 원인 분석 및 반등/손절 판단

| 데이터 | 사용 목적 |
|--------|-----------|
| `ret_1d`, `ret_5d`, `ret_20d` | 급락 폭과 기간 측정 |
| `rsi` | 30 이하: 과매도 → 반등 가능성 |
| `bb_pct` | 0.1 이하: 볼린저 하단 = 기술적 지지 |
| `volume_ratio` | 패닉 매도(고거래량) vs 투자자 외면(저거래량) 구분 |
| `pct_from_52w_low` | 52주 저점 근접 여부 = 역사적 지지선 |
| `short_ratio`, `short_ratio_5d_avg` | 공매도 공격 여부 |
| `debt_ratio`, `current_ratio` | 재무적 위기(구조적 하락) 여부 |
| `interest_coverage` | 이자 미지급 위험 |
| DART 공시 | 급락 원인 파악 (실적 쇼크·소송·대주주 매도 등) |
| 유사 과거 패턴 | 유사 급락 이후 회복 패턴 |

**판단 기준**: `ret_5d < -15%` + `rsi < 30` + `volume_ratio > 2` + 공시 없음 = 반등 가능성 높음

## 부록: 데이터 품질 참고사항

| 항목 | 주의사항 |

# 03. 시스템 아키텍처 - 논문 MERA에서 한국형 MERA로

> 목적: 원본 MERA 논문의 아이디어가 한국형 MERA 구현체에서 어떤 투자 분석 시스템으로 바뀌었는지 발표용으로 정리한다.  
> 기준 자료: 원작자 `발표_내용_정리.md`, DB 구축 흐름도, 종목선정 흐름도, 종목평가 흐름도, 최신 코드 구조  
> 구성: 1부는 발표자료 정리용, 2부는 같은 목차를 따라가는 상세 설명용이다.

> 읽기 보조: 소스코드 용어는 유지하되, 비개발자가 유추하기 어려운 용어는 첫 등장 위치에서 쉬운 의미를 함께 적었다.

# 1부. 발표자료 정리용

## 1. 프로젝트 배경과 동기

### 1-1. 주식 AI 예측의 현실적 한계

주식 예측은 일반적인 시계열 예측보다 어렵다. 같은 기술지표라도 종목 성격, 시장 상황, 섹터 분위기, 공시 이벤트에 따라 의미가 달라지기 때문이다.

```text
단일 모델의 한계
→ 모든 종목을 같은 기준으로 판단하기 어려움
→ 성장주, 가치주, 테마주, 배당주, 급락주가 서로 다른 패턴으로 움직임
→ 과거와 비슷해 보이는 패턴도 시장 국면(regime)에 따라 결과가 달라질 수 있음
```

### 1-2. 한국 주식시장 특수성

한국형 MERA는 미국/중국 시장 일반 데이터가 아니라 국내 투자 환경을 반영한다.

| 한국 시장 요소 | 발표에서 설명할 의미 |
|---|---|
| KOSPI200 중심 universe(분석 대상 종목군) | 대표 대형주 중심으로 분석 대상을 제한 |
| 6자리 종목코드 | 국내 주식 데이터 처리 방식 반영 |
| DART 공시 | 실적, 계약, 자사주, 배당 등 공식 이벤트 반영 |
| KRX 공매도 | 수급 압력과 숏커버 가능성 참고 |
| pykrx/FDR/네이버 fallback(대체 수집 경로) | 국내 데이터 수집의 불완전성을 보완 |
| 테마주/급락주 관점 | 한국 시장에서 자주 나타나는 투자 판단 축 반영 |

### 1-3. 우리가 풀고자 한 문제 정의

```text
질문:
현재 한국 주식 종목이 어떤 유형의 패턴인지 판단하고,
과거 유사 사례를 참고하며,
여러 투자 관점의 전문가가 동시에 분석한 뒤,
실제 포트폴리오 성과로 검증할 수 있을까?
```

## 2. 원본 MERA 논문 이해

### 2-1. 논문 개요

MERA는 **Retrieval-Augmented Representation**(과거 유사 사례를 반영한 주식 상태 표현)과 **Mixture of Experts**(여러 전문가 모델을 조합하는 구조)를 결합해 다양한 주식 패턴을 모델링하려는 주가 예측 모델이다.

이 논문은 "주식은 하나의 패턴으로 움직이지 않으므로, 현재 패턴과 비슷했던 과거 사례를 찾고, 상황에 맞는 expert(전문가 모델)를 활용해 예측하려는 모델"로 이해할 수 있다. 핵심은 단순히 더 복잡한 딥러닝 모델을 만든 것이 아니라, **패턴 다양성**과 **과거 유사 사례 활용**을 동시에 다루려 했다는 점이다.

### 2-2. 핵심 아이디어: Retrieval + Mixture of Experts

| 구성 | 역할 |
|---|---|
| Retrieval | 현재 주식 패턴과 유사한 과거 샘플을 찾아 예측에 참고 |
| Mixture of Experts | 하나의 모델이 모든 패턴을 처리하지 않고 여러 expert(전문가 모델)가 나누어 학습 |
| GateNet | 현재 샘플에 어떤 expert가 적합한지 판단하는 라우터 |
| Neural Expert | 서로 다른 주식 패턴을 담당하는 딥러닝 예측기 |

### 2-3. 원본 아키텍처 흐름

```text
주가 시계열 데이터
→ neural representation(모델 내부의 주식 상태 표현) 생성
→ 과거 유사 샘플 retrieval
→ 유사 샘플의 label(이후 실제 수익률) 정보 활용
→ GateNet이 적합 expert 선택/가중
→ Neural Expert가 수익률 예측
→ IC, RankIC 등으로 평가
```

### 2-4. 평가 방식: IC, RankIC

원본 논문은 추천 포트폴리오 수익률보다 예측 모델의 성능을 중심으로 평가한다. 대표적으로 IC, RankIC처럼 모델이 수익률의 방향이나 순위를 얼마나 잘 맞히는지 보는 지표를 사용한다. 쉽게 말해 "수익률이 높을 종목을 얼마나 앞쪽에 잘 세웠는가"를 보는 평가다.

### 2-5. 논문이 하는 것과 하지 않는 것

원본 MERA는 딥러닝 기반 예측 모델이다. 따라서 expert는 성장주/가치주처럼 사람이 정한 투자 스타일이 아니라, 학습 과정에서 서로 다른 패턴을 담당하도록 분화되는 neural expert에 가깝다.

## 3. 한국형 MERA: 핵심 아이디어

### 3-1. 논문 아이디어를 어떻게 재해석했는가

한국형 MERA는 원본 논문의 구조를 그대로 복제한 것이 아니라, 핵심 아이디어를 한국 시장용 LLM 투자 분석 시스템으로 재해석했다.

```text
원본 MERA
딥러닝 representation(내부 표현) + retrieval(유사 사례 검색) + neural expert(딥러닝 전문가)

한국형 MERA
기술지표 패턴 텍스트/embedding(숫자 벡터 변환) + ChromaDB RAG(과거 유사패턴 검색) + LLM 투자 전문가
```

### 3-2. 딥러닝 모델에서 LLM 전문가 시스템으로 전환한 이유

LLM 기반 구조는 예측값만 내는 것이 아니라, 왜 그 종목을 선택했는지 근거와 리스크를 함께 제시할 수 있다. 이 전환은 **예측 정확도 중심 모델에서 설명 가능한 투자 판단 시스템으로의 전환**으로 이해할 수 있다.

### 3-3. 한 문장 요약

> 한국형 MERA는 원본 MERA의 Retrieval + MoE(Mixture of Experts, 여러 전문가 조합) 구조를 한국 주식 데이터, 과거 유사패턴 RAG, 5개 LLM 투자 전문가, 포트폴리오 백테스트로 재구성한 시스템이다.

## 4. 원본 MERA vs 한국형 MERA 구조 대비

### 4-1. 구성요소 1:1 대응 비교

| 원본 MERA | 한국형 MERA | 발표용 해석 |
|---|---|---|
| Representation | 기술지표 snapshot(특정 시점의 종목 상태 요약) + 패턴 텍스트 + embedding | 주식 상태를 검색 가능한 표현으로 변환 |
| Retrieval | 과거 유사 샘플 검색 | ChromaDB `stock_patterns`에서 유사 과거패턴 Top-K(상위 K개) 검색 |
| GateNet | Gate Agent | 5개 전문가별 적합도 가중치 계산 |
| Neural Expert | Growth/Value/Theme/Dividend/Crisis LLM Expert | 사람이 이해할 수 있는 투자 스타일별 분석 |
| Prediction Head | Expert picks(전문가 추천 종목) + Aggregator(추천 결과 통합기) | BUY/HOLD/SELL과 최종 Top-5 포트폴리오 구성 |
| IC/RankIC 평가 | 백테스트 지표 | 적중률, 평균수익률, ARR, MDD, Sortino, Calmar |

### 4-2. 구조 차이: 단일 모델 vs 파이프라인 시스템

```text
원본 MERA:
end-to-end(입력부터 예측까지 한 모델 안에서 학습) 학습 모델에 가까움

한국형 MERA:
DB 구축 → RAG 검색 → LLM Expert → Aggregator(추천 결과 통합) → 백테스트로 이어지는 파이프라인
```

### 4-3. 신뢰 정보 방식 차이

| 구분 | 원본 MERA | 한국형 MERA |
|---|---|---|
| 신뢰 기준 | 예측 성능 지표 | 판단 근거, RAG 유사 사례, confidence(모델이 제시한 신뢰도), 백테스트 |
| 장점 | 정량 실험 기반 검증 | 한국 시장 맥락과 설명 가능성 |
| 주의점 | expert 의미를 사람이 직접 해석하기 어려움 | LLM 판단 품질과 데이터 품질에 영향 받음 |

## 5. 우리가 개선하고자 한 것

### 5-1. 원본 한계 보완

원본 MERA의 한계는 모델 내부 판단이 블랙박스에 가깝고, 한국 시장 데이터 구조가 직접 반영되어 있지 않다는 점이다.

```text
원본 MERA의 한계로 볼 수 있는 부분
→ expert가 어떤 투자 스타일을 의미하는지 사람이 직접 설명하기 어려움
→ 한국 공시, 공매도, 국내 데이터 수집 환경이 직접 반영되지 않음
→ 예측 성능 평가는 가능하지만, 투자 판단 근거를 설명하기는 제한적
→ 실제 포트폴리오 구성과 투자 리포트 생성까지는 별도 시스템이 필요
```

### 5-2. 한국 시장 특수성 반영 데이터 확장

```text
가격/거래량: pykrx, FDR fallback(대체 수집 경로)
재무: pykrx, DART, 네이버 fallback(대체 수집 경로)
공시: DART
공매도: KRX/pykrx
패턴 검색: OpenAI embedding(텍스트를 숫자 벡터로 변환) + ChromaDB(벡터 검색 DB)
```

### 5-3. 전문가 다양화

한국형 MERA는 하나의 AI가 모든 종목을 판단하지 않고, 투자 스타일별 전문가를 분리한다.

| Expert | 담당 관점 |
|---|---|
| Growth | 실적 성장과 모멘텀 |
| Value | 저평가와 재무 안정성 |
| Theme | 정책, 이슈, 단기 수급 |
| Dividend | 배당 안정성과 방어적 성격 |
| Crisis | 급락 원인과 반등 가능성 |

### 5-4. 설명 가능한 투자 판단

Expert는 단순 점수만 내지 않고 `signal`(BUY/HOLD/SELL 판단), `confidence`(신뢰도), `target_return`(목표 수익률), `reason`(판단 근거), `pros`(긍정 요인), `cons`(주의 요인)를 포함한 구조화된 결과를 만든다.

이 구조의 장점은 추천 결과를 사후에 검토할 수 있다는 점이다. 예를 들어 어떤 종목이 통합 포트폴리오에 들어갔다면, 어떤 expert가 추천했는지, confidence가 어느 정도였는지, 긍정 요인과 주의 요인이 무엇이었는지 확인할 수 있다. 즉 **블랙박스 예측에서 설명 가능한 투자 판단으로 확장한 지점**이다.

## 6. 시스템 아키텍처: 4단계 파이프라인

### 6-1. 전체 흐름

원작자 흐름도 기준으로 한국형 MERA는 세 개의 큰 흐름으로 이해하는 것이 가장 자연스럽다. 첫 번째 흐름은 과거 유사패턴을 저장하는 **사전 DB 구축**, 두 번째 흐름은 현재 시점의 종목을 고르는 **일별 종목 선정**, 세 번째 흐름은 추천이 실제 수익으로 이어졌는지 확인하는 **종목 평가**다.

```text
① KOSPI200 과거 유사패턴 DB 구축
        ↓
② 일별 종목 선정
   Screener(RAG 검색 포함) → Gate → 5 Expert → Aggregator
        ↓
③ 종목 평가
   월별/주별 백테스트로 실제 수익률 검증
```

사전 DB 구축은 다음 순서로 진행된다.

```text
KOSPI200 전체 종목
→ OHLCV 수집
→ 기술지표 계산
→ Snapshot + label 생성
→ 패턴 텍스트 + Embedding
→ ChromaDB 저장
```

### 6-2. 1단계: 데이터 수집 및 전처리

현재 분석일 기준으로 OHLCV(시가·고가·저가·종가·거래량), 기술지표, 재무, 공시, 공매도, 섹터 정보를 수집해 candidate(분석 후보 종목 데이터 묶음)를 만든다.

```text
ticker / name / sector / market
snapshot(특정 날짜의 종목 상태 요약)
financials
news_text
current_text
retrieved_patterns
```

원작자 종목선정 흐름도 기준으로 1단계 데이터 수집은 다음 네 묶음으로 나뉜다.

| 데이터 묶음 | 내용 | 역할 |
|---|---|---|
| OHLCV + 기술지표 | 가격, 거래량, RSI, MACD, ADX, 이동평균, 변동성 | 현재 주가 흐름과 기술적 상태 파악 |
| 재무지표 | PER/PBR/EPS/BPS, ROE, FCF, 부채비율, 이자보상 | 가치·배당·위기 판단 근거 |
| 공시(DART) | 최근 30일 이내 공시, 주요사항보고, 조회공시 | 이벤트와 리스크 맥락 제공 |
| 공매도·52주·섹터 | 공매도 비율, 52주 위치, 섹터 평균 비교 | 수급 압력과 상대적 위치 판단 |

### 6-3. 2단계: RAG/과거 유사 패턴 저장 및 검색

사전에 구축한 KOSPI200 과거 패턴 DB에서 현재 종목과 유사한 과거 사례를 검색한다.

```text
현재 종목 snapshot(특정 시점 상태)
→ 패턴 텍스트 생성
→ embedding(검색을 위한 숫자 벡터) 생성
→ ChromaDB `stock_patterns` 검색
→ 유사 과거패턴 Top-5 반환
→ label_5d/10d/20d(이후 5일/10일/20일 실제 수익률) 기반 결과 참고
```

이때 RAG embedding에 들어가는 핵심 텍스트는 기술지표 기반 패턴 설명이다. 최근 공시와 뉴스는 별도 `news_text`(뉴스·공시 요약) 맥락으로 Expert 분석에 전달되며, 현재 코드 기준으로 RAG embedding 텍스트에 항상 포함되는 구조는 아니다.

RAG 검색 결과는 Expert에게 단순 참고 문서로 전달되는 것이 아니라, 유사 과거패턴의 실제 수익률 통계와 함께 제공된다.

```text
유사 과거패턴 Top-5
→ 각 패턴의 label_5d / label_10d / label_20d 확인
→ 상승 적중률과 평균 수익률 계산
→ Expert prompt에 첨부
→ Expert가 confidence 판단 시 참고
```

### 6-4. 3단계: Screener → Gate → 5개 Expert 병렬 분석

Screener(1차 후보 선별기)는 전문가별 휴리스틱 스코어를 계산해 각 전문가별 Top-15 후보군을 만들고, Gate(전문가 적합도 계산기)는 종목별 전문가 적합도 가중치를 계산한다. 이후 5개 Expert가 병렬로 후보를 분석해 각자 최대 5개 picks(추천 종목)를 만든다.

```text
전문가별 후보 스코어링
→ growth/value/theme/dividend/crisis 후보군 생성(각 Top-15)
→ Gate weight(전문가별 반영 비중) 계산
→ 5개 Expert 병렬 분석
→ Expert별 최대 5개 picks 출력
```

Gate는 전문가 하나를 고르는 스위치가 아니라, 5개 관점의 적합도를 모두 계산한다.

소스에서는 Gate에게 소수의 전문가만 고르라고 시키지 않고, "각 전문가의 적합도를 평가"하라고 지시한다.

```text
당신은 주식 패턴 분류 전문가입니다.
현재 종목의 패턴과 유사한 과거 사례를 분석하여
각 투자 전문가의 적합도를 평가합니다.
반드시 JSON 형식으로만 응답하세요.

현재 패턴에 대한 각 전문가의 적합도를 0.0~1.0으로 평가하세요.
- 1.0: 이 패턴의 핵심 전문가
- 0.5: 참고 가능
- 0.0: 이 패턴과 무관
```

```json
{
  "weights": {
    "growth": 0.82,
    "value": 0.10,
    "theme": 0.30,
    "dividend": 0.05,
    "crisis": 0.15
  },
  "pattern_type": "실적모멘텀 성장주",
  "reason": "거래량 증가와 실적 모멘텀이 강함"
}
```

### 6-5. 4단계: Aggregator → 포트폴리오 구성

Aggregator(추천 결과 통합기)는 전문가별 picks를 종목 단위로 묶고, BUY와 confidence 조건을 통과한 종목을 대상으로 최종 Top-5 포트폴리오를 만든다.

```text
Expert picks 수집
→ 종목별 그룹화
→ BUY + confidence 0.60 이상 필터
→ gate_weight(전문가 가중치) × confidence(신뢰도) × score(매력도 점수) 반영
→ combined_portfolio Top-5 생성
```

## 7. 전문가 에이전트별 데이터 전략

### 7-1. Gate Agent: 종목별 전문가 가중치 배분

Gate Agent는 각 종목이 성장주형인지, 가치주형인지, 테마주형인지처럼 하나의 라벨만 붙이지 않는다. 5개 전문가 관점이 각각 얼마나 적합한지 가중치로 계산한다. 여기서 가중치는 최종 포트폴리오 점수에 반영되는 "전문가 의견의 반영 비중"에 가깝다.

Gate Agent는 소수의 전문가만 선택하지 않고, 5개 전문가 모두에 대한 적합도 가중치를 요구한다.

```text
현재 패턴에 대한 각 전문가의 적합도를 0.0~1.0으로 평가하세요.
- 1.0: 이 패턴의 핵심 전문가
- 0.5: 참고 가능
- 0.0: 이 패턴과 무관

출력 형식:
{
  "weights": {
    "growth": 0.8,
    "value": 0.1,
    "theme": 0.3,
    "dividend": 0.0,
    "crisis": 0.2
  },
  "pattern_type": "실적모멘텀 성장주",
  "reason": "..."
}
```

### 7-2. 성장주 전문가 Growth

Growth Expert는 실적 성장과 주가 모멘텀을 중심으로 후보를 고른다.

```text
역할:
당신은 한국 성장주(고PER, 실적 모멘텀) 전문 애널리스트입니다.

판단 기준:
1. 실적 모멘텀 — 매출·영업이익 YoY 성장률이 높은 순
2. 주가 모멘텀 — RSI 45~70, MACD 양전환, 거래량 동반 상승
3. 섹터 성장성 — AI·반도체·2차전지·바이오 등 고성장 섹터 우선
4. RAG 과거 패턴 — 유사 모멘텀 패턴의 적중률·평균수익을 confidence(신뢰도)에 반영
5. 공시 활용 — 대규모 수주·계약은 BUY 가산점, 유상증자·전환사채는 희석 리스크로 판단
```

### 7-3. 가치주 전문가 Value

Value Expert는 저평가와 재무 안정성을 중심으로 후보를 고른다.

```text
역할:
당신은 한국 가치주(저PBR/PER, 자산가치, 안정 현금흐름) 전문 애널리스트입니다.

판단 기준:
1. 밸류에이션 — PBR < 1.5, 섹터 대비 저PER
2. Graham Number 대비 현재가 위치 (낮을수록 매력적)
3. 재무 안정성 — 부채비율·이자보상배율
4. 저평가 해소 촉매 — 배당수익률·FCF
5. RAG 과거 패턴 — 유사 저평가 패턴에서 실제 주가 회복 여부를 confidence(신뢰도)에 반영
6. 공시 활용 — 자기주식 취득은 BUY 가산점, 전환사채·유상증자는 희석 리스크
```

### 7-4. 테마주 전문가 Theme

Theme Expert는 정책 수혜, 이슈 모멘텀, 단기 수급을 중심으로 후보를 고른다.

```text
역할:
당신은 한국 테마주(정책수혜, 이슈 모멘텀, 단기 급등) 전문 애널리스트입니다.

판단 기준:
1. 최근 공시·정책 수혜 직접성 (공시 내용 반영)
2. 거래량 폭발 + 주가 모멘텀 (RSI 70 미만 우선)
3. 테마 사이클 위치 (초기 진입 우선, 말기 배제)
4. RAG 과거 패턴 — 유사 급등 패턴 이후 실제 수익률 추이를 confidence(신뢰도)에 반영
5. 공시 활용 — 수주·계약·MOU는 테마 직접 수혜 확인, 불성실공시는 confidence 하향
```

### 7-5. 배당주 전문가 Dividend

Dividend Expert는 배당 지속 가능성과 방어적 성격을 중심으로 후보를 고른다.

```text
역할:
당신은 한국 배당주(고배당, 방어적 섹터, 안정 수익) 전문 애널리스트입니다.

판단 기준:
1. 배당수익률 + FCF 기반 지속 가능성 (배당성향 30~70% 적정)
2. 방어적 특성 — 낮은 베타·변동성
3. 재무 건전성 — 부채비율·이자보상배율
4. 금리 환경 대비 배당 매력도
5. RAG 과거 패턴 — 유사 방어주 패턴의 안정성을 confidence(신뢰도)에 반영
6. 공시 활용 — 배당 결정·증액은 BUY 가산점, 유상증자는 배당 재원 희석 우려
```

### 7-6. 위기종목 전문가 Crisis

Crisis Expert는 급락 원인이 일시적인지 구조적인지 구분하고, 반등 가능성이 높은 후보를 고른다.

```text
역할:
당신은 한국 주식 위기종목(급락 후 반등 가능성) 전문 애널리스트입니다.

판단 기준:
1. 급락 원인 분석 — 일시적 악재 vs 구조적 문제 구분
2. 기술적 과매도 정도 — RSI 30 이하, BB 하단 접근
3. 재무 건전성 — 이자보상·유동비율 (반등 지속 가능성)
4. RAG 과거 패턴 — 유사 급락 패턴 이후 실제 반등 성공률을 confidence(신뢰도)에 반영
5. 공시 활용 — 횡령·배임·불성실공시는 구조적 문제로 판단, 조회공시는 악재 공식화 여부 확인
```

공통 Expert 출력 구조는 모든 전문가에게 동일하게 적용된다.

Expert에게는 단순히 "종목을 추천하라"고 묻지 않는다. 여러 후보 종목 중 최대 5개를 선별하고, 정해진 JSON(정해진 항목을 가진 데이터 형식) 형식으로 투자 근거와 주의 요인을 함께 출력하게 한다.

Expert Prompt는 단일 종목을 하나씩 분석하는 구조가 아니라, Screener가 넘긴 여러 후보 종목 중 최대 5개를 선별하는 배치 분석(여러 후보를 한 번에 비교·선별) 구조다.

```text
당신은 한국 주식시장 전문 애널리스트입니다.
아래 후보 종목에서 투자 매력도가 높은 종목을 선별하여 상세 분석하세요.
BUY(매수) 종목을 우선하되, HOLD(보유)/SELL(매도)도 근거가 명확하면 포함하세요.
각 종목의 pros·cons에는 반드시 구체적인 수치를 포함하세요.

[RAG 활용 지침]
각 종목의 [유사 과거 패턴 (RAG)] 섹션을 반드시 참고하세요.
- 적중률이 높고(4/5 이상) 평균수익이 플러스인 종목은 confidence를 높게 설정하세요.
- 적중률이 낮거나(2/5 이하) 평균수익이 마이너스인 종목은 confidence를 낮추거나 HOLD로 판단하세요.
- RAG 통계는 펀더멘털 분석을 보완하는 증거로 활용하세요. (RAG만으로 BUY하지 말것)

출력 형식:
{
  "picks": [
    {
      "ticker": "005930",
      "name": "종목명",
      "signal": "BUY",
      "confidence": 0.85,
      "target_return": 0.10,
      "horizon_days": 10,
      "score": 8,
      "reason": "핵심 투자 근거 (2~3문장)",
      "pros": ["긍정 요인1", "긍정 요인2", "긍정 요인3"],
      "cons": ["리스크 요인1", "리스크 요인2"]
    }
  ]
}
```

## 8. 성과 및 백테스트 결과

### 8-1. 평가 지표

| 지표 | 의미 |
|---|---|
| 적중률 | 추천 종목 중 수익이 난 비율 |
| 평균 수익률 | 추천 종목들의 실제 평균 수익률 |
| ARR | 연환산 수익률, 즉 기간 수익률을 1년 기준으로 환산한 값 |
| MDD | 최대 낙폭, 즉 평가 기간 중 고점 대비 가장 크게 빠진 비율 |
| Sortino | 하락 변동성만 위험으로 보고 계산한 위험 대비 수익률 |
| Calmar | 최대 낙폭 대비 연환산 수익률 |

### 8-2. 백테스트 결과 요약

현재 저장된 리포트 기준으로는 월별/주별 평가 결과가 분리되어 있다.

| 리포트 | 통합 포트폴리오 요약 |
|---|---|
| `reports/backtest_2025/summary_monthly.txt` | 평균 수익률 약 +5.0%, 적중률 약 63% |
| `reports/backtest_2026/summary_monthly.txt` | 평균 수익률 약 +7.1%, 적중률 약 58% |
| `reports/backtest_2026/summary_weekly.txt` | 평균 수익률 약 +1.2%, 적중률 약 62% |

### 8-3. 전문가별 성과 비교

전문가별 포트폴리오와 통합 포트폴리오를 따로 평가하기 때문에, 어떤 관점이 특정 기간에 더 유효했는지 비교할 수 있다. 예를 들어 성장주, 가치주, 테마주, 배당주, 위기종목 포트폴리오를 각각 월별/주별로 평가하고, 최종 combined 포트폴리오(전문가 추천을 합친 통합 포트폴리오)와 비교한다.

원작자 종목평가 흐름도 기준 평가 대상은 다음과 같다.

```text
전문가별 포트폴리오 5개 × 5명
+ 통합 포트폴리오 5개
= 최대 30개 종목 평가
```

평가 방식은 두 가지다.

| 평가 방식 | 선정 시점 | 평가 시점 |
|---|---|---|
| 월별 평가 | 월초 선정 | 월말 평가 |
| 주별 평가 | 월요일 선정 | 5영업일 후 평가 |

이 비교는 단순히 "어떤 expert가 제일 좋았다"를 고르는 목적만은 아니다. 특정 기간에는 성장주나 테마주가 강할 수 있고, 다른 기간에는 배당주나 위기종목 반등 전략이 상대적으로 유리할 수 있다. 따라서 전문가별 성과 비교는 시장 국면(regime)에 따라 어떤 투자 관점이 작동했는지 해석하는 자료가 된다.

### 8-4. 한계 및 해석 주의사항

백테스트 결과는 모델의 가능성을 보여주는 참고 자료지만, 실전 투자 성과를 그대로 보장하지는 않는다. 특히 한국형 MERA는 LLM 판단, RAG 검색 품질, 데이터 수집 안정성에 영향을 받기 때문에 성과 해석에 몇 가지 한계가 있다.

| 한계 요인 | 해석상 주의점 |
|---|---|
| 평가 기간 제한 | 특정 기간의 시장 분위기에 성과가 크게 좌우될 수 있음 |
| 거래비용 미반영 가능성 | 수수료, 세금, 슬리피지를 반영하면 실제 수익률은 낮아질 수 있음 |
| universe(분석 대상 종목군) 제한 | KOSPI200 중심 결과이므로 중소형주나 KOSDAQ 전체로 일반화하기 어려움 |
| RAG 품질 의존 | 유사 과거패턴이 실제로 의미 있는 사례인지에 따라 confidence 판단이 달라질 수 있음 |
| LLM 판단 변동성 | 같은 데이터라도 모델 응답이 완전히 고정되지 않을 수 있음 |
| 생존편향 가능성 | 현재 남아 있는 종목 중심 데이터라면 상장폐지·거래정지 종목의 영향이 과소평가될 수 있음 |
| 시장 국면(regime) 변화 | 금리, 환율, 정책, 수급 환경이 바뀌면 과거 유사패턴의 설명력이 약해질 수 있음 |

따라서 이 성과는 **투자 전략의 최종 검증 결과**라기보다, "과거 유사패턴 RAG와 전문가별 LLM 판단을 결합한 포트폴리오가 일정 기간에서 어떤 결과를 냈는지 확인한 실험 결과"로 해석하는 것이 적절하다.

## 9. 결론 및 향후 과제

### 9-1. 프로젝트 요약

한국형 MERA는 원본 MERA의 Retrieval + MoE 구조를 한국 주식시장에 맞게 재해석한 LLM 기반 투자 분석 파이프라인이다.

한 문장으로 정리하면, 이 프로젝트는 **과거 유사패턴을 검색하는 RAG**와 **투자 스타일별 LLM Expert**를 결합해 한국 주식 종목을 선별하고, 그 결과를 포트폴리오와 백테스트로 검증하는 시스템이다.

### 9-2. 원본 MERA 대비 기여

```text
과거 유사패턴 DB 구축
→ 한국 데이터 기반 RAG 검색
→ Gate weight 기반 전문가 적합도 계산
→ 5개 LLM Expert 병렬 분석
→ Aggregator(추천 결과 통합기) 기반 Top-5 포트폴리오
→ 월별/주별 백테스트 평가
```

### 9-3. 향후 과제

| 과제 | 의미 |
|---|---|
| 거래비용/슬리피지 반영 | 실전 투자 성과에 더 가까운 평가 필요 |
| RAG 품질 검증 | 유사패턴 검색이 실제로 유효한지 정량 검증 필요 |
| LLM 일관성 관리 | 같은 입력에 대한 판단 안정성 점검 필요 |
| benchmark(비교 기준) 비교 | KOSPI200, 단순 모멘텀, 기존 ML 모델과 비교 필요 |
| 데이터 coverage 확장 | KOSDAQ150, 중소형주, 상장폐지/거래정지 처리 보강 가능 |

# 2부. 상세 설명용

## 1. 프로젝트 배경과 동기

주가 예측 모델이 어려운 이유는 데이터가 많아서가 아니라, 같은 데이터의 의미가 상황마다 달라지기 때문이다. 예를 들어 RSI가 높다는 사실은 어떤 종목에서는 강한 추세의 지속일 수 있고, 다른 종목에서는 단기 과열의 신호일 수 있다. 거래량 급증도 마찬가지다. 성장주에서는 기관 수급 유입일 수 있지만, 테마주에서는 단기 이슈 과열일 수 있다.

그래서 주식 AI 모델은 단순히 "과거 20일 가격을 보고 다음 수익률을 맞힌다" 수준을 넘어서야 한다. 현재 종목이 어떤 성격의 종목인지, 비슷한 과거 사례가 있었는지, 어떤 투자 관점에서 보는 것이 적절한지까지 함께 판단해야 한다.

한국 시장에서는 이 문제가 더 뚜렷하다. 공시 이벤트, 테마성 수급, 공매도, 배당 정책, 대형주 중심 수급 등이 종목 움직임에 큰 영향을 준다. 따라서 한국형 MERA는 원본 MERA의 아이디어를 국내 데이터 환경에 맞춰 다시 구성한다.

이 프로젝트의 문제 정의는 다음처럼 정리할 수 있다.

```text
현재 종목의 상태를 여러 데이터로 표현하고,
과거 유사한 한국 주식 패턴을 찾아 참고하며,
성장/가치/테마/배당/위기 관점의 전문가가 나누어 분석하고,
최종 추천이 실제 수익률로 이어졌는지 평가한다.
```

## 2. 원본 MERA 논문 이해

원본 MERA의 핵심 문제의식은 **주식 패턴의 다양성**이다. 모든 주식이 같은 패턴으로 움직이지 않기 때문에 하나의 모델이 모든 상황을 동일하게 처리하면 성능이 제한될 수 있다.

MERA는 이 문제를 두 가지 아이디어로 풀려고 한다.

첫째, Retrieval-Augmented Representation이다. 현재 샘플만 보고 예측하지 않고, 과거에 이와 비슷한 샘플을 검색해 그 샘플들이 이후 어떤 수익률을 보였는지 참고한다. 금융 관점에서는 "과거 비슷한 장면에서 시장이 어떻게 반응했는가"를 보는 방식이다.

둘째, Mixture of Experts다. 하나의 모델이 모든 주식 패턴을 처리하지 않고, 여러 expert(전문가 모델)가 서로 다른 패턴을 담당하게 한다. GateNet은 현재 샘플이 어느 expert에게 더 적합한지 판단하는 라우터 역할을 한다.

다만 원본 MERA의 expert는 사람이 정한 성장주/가치주 같은 역할이 아니다. 학습 과정에서 데이터가 자동으로 분화시킨 neural expert다. 그래서 예측 성능 측면에서는 강점이 있지만, 발표에서 "성장 전문가가 골랐다"처럼 해석하면 정확하지 않다.

원본 논문에서의 평가는 주로 IC, RankIC 같은 예측 성능 지표를 사용한다. 이는 모델이 수익률 순위를 얼마나 잘 맞히는지 보는 지표에 가깝다. 실제 포트폴리오를 만들어 매매했을 때 수익이 났는지와는 평가 목적이 조금 다르다.

## 3. 한국형 MERA: 핵심 아이디어

한국형 MERA는 원본 MERA의 구조를 딥러닝 모델로 그대로 재현하기보다, 그 아이디어를 한국 시장용 투자 분석 시스템으로 재해석한다.

가장 중요한 변환은 세 가지다.

```text
1. neural representation
   → 기술지표 snapshot(특정 시점의 종목 상태), 자연어 패턴 텍스트, embedding(검색용 숫자 벡터)

2. retrieval memory
   → KOSPI200 과거 거래일 패턴을 저장한 ChromaDB(벡터 검색 DB)

3. neural expert
   → 성장, 가치, 테마, 배당, 위기 관점의 LLM Expert
```

재무와 공시는 RAG embedding의 핵심 텍스트라기보다 Expert 분석 맥락에 추가되는 정보다. 이 전환의 장점은 설명 가능성이다. 딥러닝 모델은 내부 벡터와 expert가 어떤 의미인지 사람이 직접 설명하기 어렵다. 반면 한국형 MERA는 "이 종목은 성장 관점에서 매력적이고, 과거 유사 패턴의 5일 수익률이 양호했으며, Gate가 growth 관점에 높은 가중치를 주었다"처럼 설명할 수 있다.

물론 이 구조는 원본 MERA처럼 데이터 입력부터 예측까지 하나의 딥러닝 모델 안에서 학습되는 end-to-end(입력부터 출력까지 한 번에 학습되는 방식) 모델은 아니다. 한국형 MERA는 논문 모델의 완전 재현이라기보다, 논문 아이디어의 한국 시장형 시스템 구현에 가깝다.

## 4. 원본 MERA vs 한국형 MERA 구조 대비

원본 MERA와 한국형 MERA는 이름은 비슷하지만 신뢰를 만드는 방식이 다르다.

원본 MERA는 모델 학습과 정량 평가가 핵심이다. representation(모델 내부 표현)과 expert(전문가 모델)는 모델 내부에서 학습되고, 성능은 IC/RankIC 같은 지표로 평가된다. 따라서 논문에서는 예측 모델로서의 성능 검증이 중심이다.

한국형 MERA는 투자 판단의 흐름을 명시적으로 만든다. 데이터를 수집하고, 과거 유사패턴을 찾고, 전문가별 관점을 부여하고, 최종 포트폴리오를 구성한 뒤 백테스트로 확인한다. 여기서 핵심은 예측값 하나가 아니라 판단 근거와 포트폴리오 생성 과정이다.

구조적으로 보면 다음과 같다.

```text
원본 MERA
시계열 데이터 → representation(내부 표현) → retrieval(유사 사례 검색) → GateNet(전문가 라우터) → Neural Expert → 예측

한국형 MERA
한국 주식 데이터 → 패턴 텍스트/embedding(검색용 숫자 벡터) → ChromaDB RAG
→ Gate Agent(전문가 가중치 계산) → 5개 LLM Expert → Aggregator(추천 결과 통합) → 포트폴리오/백테스트
```

특히 Gate의 의미가 중요하다. 한국형 MERA에서 Gate는 5개 전문가 중 하나만 선택하지 않는다. 각 전문가 관점이 얼마나 적합한지 0.0~1.0 가중치로 계산하고, 이 값은 Aggregator에서 최종 점수에 반영된다.

## 5. 우리가 개선하고자 한 것

첫 번째 개선은 한국 데이터 환경 반영이다. 주가와 거래량만 보는 것이 아니라 재무, 공시, 공매도, 섹터 정보까지 결합한다. 한국 시장에서는 DART 공시나 공매도, 배당 정책, 단기 테마 수급이 투자 판단에 큰 영향을 주기 때문이다.

두 번째 개선은 투자 관점의 분리다. 성장주와 가치주는 좋은 종목을 판단하는 기준이 다르다. 성장주는 실적 증가율과 모멘텀을 중시하고, 가치주는 저평가와 재무 안정성을 중시한다. 테마주는 공시와 수급이 중요하고, 배당주는 현금흐름과 배당 지속 가능성이 중요하며, 위기종목은 급락 원인이 일시적인지 구조적인지 봐야 한다.

세 번째 개선은 설명 가능한 출력이다. Expert는 단순히 확률 하나를 내지 않고, 다음 구조로 결과를 낸다. 여기서 `picks`는 추천 종목 목록, `confidence`는 신뢰도, `pros/cons`는 긍정 요인과 주의 요인이다.

```json
{
  "picks": [
    {
      "ticker": "005930",
      "name": "삼성전자",
      "signal": "BUY",
      "confidence": 0.82,
      "target_return": 0.10,
      "horizon_days": 20,
      "score": 8,
      "reason": "핵심 투자 근거",
      "pros": ["긍정 요인"],
      "cons": ["주의 요인"]
    }
  ]
}
```

이 구조 덕분에 결과는 "AI가 추천했다"에서 끝나지 않는다. 어떤 관점에서, 어떤 근거로, 어떤 리스크를 감수하고 추천했는지까지 함께 확인할 수 있다.

## 6. 시스템 아키텍처: 4단계 파이프라인

한국형 MERA의 시스템은 4단계 파이프라인으로 볼 수 있지만, 실제로는 사전 DB 구축이 먼저 있다.

사전 단계에서는 KOSPI200 과거 거래일 패턴 DB를 만든다. OHLCV(시가·고가·저가·종가·거래량)를 수집하고, RSI/MACD/Bollinger Band/ADX/MFI/이동평균/변동성 같은 기술지표를 계산한다. 이후 특정 날짜의 종목 상태를 snapshot으로 만들고, 그 이후 5일/10일/20일 수익률을 label(이후 실제 수익률)로 붙인다. 마지막으로 이 패턴을 자연어 텍스트로 만들고 OpenAI embedding을 생성해 ChromaDB에 저장한다.

이 DB는 현재 종목을 분석할 때 "과거에 비슷한 패턴이 있었는가"를 찾는 기억장치 역할을 한다.

원작자 DB 구축 흐름도 기준으로 보면 이 사전 단계는 다음 의미를 가진다.

```text
OHLCV 수집
→ 기술지표 계산
→ 날짜별 snapshot 생성
→ label_5d / label_10d / label_20d 부여
→ 패턴 텍스트와 embedding 생성
→ ChromaDB `stock_patterns` 저장
```

여기서 중요한 점은 label이 예측값이 아니라 과거에 이미 발생한 실제 결과라는 것이다. 예를 들어 2024년 3월 4일의 어떤 종목 패턴에 `label_5d`가 붙어 있다면, 이는 그 날짜 이후 5거래일 동안 실제로 얼마의 수익률이 났는지를 의미한다.

일별 실행 흐름은 다음과 같다.

```text
START
→ screener
→ gate
→ growth/value/theme/dividend/crisis Expert 병렬 실행
→ aggregator
→ reporter
→ END
```

이 흐름은 `agents/graph.py`의 LangGraph 구조와 맞닿아 있다. LangGraph는 여러 분석 단계를 순서대로 연결하는 실행 흐름 관리 도구로 이해하면 된다. `scheduler/pipeline.py`의 `run_daily()`는 분석 날짜와 horizon(평가 기간)을 정하고, 이전 포트폴리오 평가와 일별 종목 선정 흐름을 실행한다.

1단계에서 `agents/screener.py`의 `screener_node()`는 종목별 데이터를 수집하고 전문가별 후보군을 만든다. 이때 가격·기술지표뿐 아니라 재무, DART 공시, 공매도, 52주 위치, 섹터 비교 정보가 함께 들어간다. 2단계에서는 현재 패턴 embedding으로 ChromaDB에서 유사 과거패턴을 찾고, 유사 패턴의 실제 수익률 label을 Expert 판단 근거로 넘긴다. 3단계에서는 `agents/gate_agent.py`의 `gate_node()`가 전문가 가중치를 만들고, `agents/experts.py`의 Expert들이 병렬 분석한다. 4단계에서는 `portfolio/aggregator.py`의 `aggregator_node()`가 picks(전문가 추천 종목 목록)를 합쳐 최종 포트폴리오를 만든다.

원작자 종목선정 흐름도에서 특히 중요한 구조는 후보 압축이다.

```text
KOSPI200 전체
→ Screener가 전문가별 Top-15 후보 생성
→ 각 Expert가 자기 후보군에서 최대 5개 picks 선택
→ Aggregator가 combined Top-5 포트폴리오 생성
```

이 구조 덕분에 LLM이 모든 종목을 무작정 분석하지 않고, 1차로 압축된 후보 안에서 투자 관점별 판단을 수행한다.

## 7. 전문가 에이전트별 데이터 전략

한국형 MERA가 역할을 나누는 기준은 원본 MERA와 다르다. 원본은 데이터가 학습한 숨은 패턴을 expert가 나누어 담당한다. 한국형 MERA는 사람이 이해할 수 있는 투자 스타일을 기준으로 expert를 나눈다.

여기서 중요한 점은 "전문가를 하나만 고르는 구조"가 아니라는 점이다. Gate는 종목마다 성장, 가치, 테마, 배당, 위기 관점이 각각 얼마나 적합한지 가중치를 계산한다. 예를 들어 어떤 종목은 growth 0.8, theme 0.3, crisis 0.2처럼 여러 관점이 동시에 일부 반영될 수 있다. 이렇게 하면 한 종목을 단일 라벨로 고정하지 않고, 복합적인 투자 성격을 표현할 수 있다.

각 expert의 기준은 다음처럼 정리할 수 있다.

```text
Growth:
실적 성장, EPS, 매출/영업이익 증가율, RSI/MACD, 거래량 모멘텀

Value:
PBR/PER, Graham Number, ROE, FCF, 부채비율, 섹터 대비 저평가

Theme:
공시·정책 수혜 직접성, 거래량 급증, RSI 70 미만, 테마 사이클 위치

Dividend:
배당수익률, DPS, 배당성향, FCF, beta, 방어적 성격

Crisis:
급락 원인, RSI 30 이하, Bollinger Band 하단 접근, 유동비율, 이자보상
```

프롬프트는 이 구조를 강제하는 장치다. LLM에게 아무 질문이나 던지는 것이 아니라, 역할과 판단 기준을 먼저 주고, 후보 종목과 RAG 결과를 제공한 뒤, 정해진 JSON(정해진 항목을 가진 데이터 형식)으로 출력하게 한다. 이 때문에 한국형 MERA의 LLM은 자유로운 대화형 챗봇이라기보다, 입력과 출력 규칙이 정해진 분석 모듈에 가깝다.

각 expert는 후보 종목 전체를 한 번에 받아 그중 최대 5개를 선별한다. 따라서 "삼성전자 하나를 분석해줘" 같은 단일 종목 질의가 아니라, Screener가 만든 후보군 안에서 자기 관점에 맞는 종목을 고르는 배치 선별 방식이다. 이 구조는 실제 투자 의사결정에서 여러 후보를 놓고 비교하는 방식과 더 비슷하다.

특히 RAG 지침은 중요하다.

```text
유사 과거 패턴의 적중률이 높고, 예를 들어 4/5 이상이며 평균수익률이 플러스라면 confidence를 높게 설정한다.
반대로 적중률이 2/5 이하이거나 평균수익률이 마이너스라면 confidence를 낮추거나 HOLD로 판단한다.
하지만 RAG만으로 BUY하지 말고 펀더멘털 분석을 보완하는 증거로 사용한다.
```

이 부분은 한국형 MERA가 단순 RAG 챗봇이 아니라, 과거 유사 사례를 투자 판단의 보조 근거로 쓰는 구조임을 보여준다.

다만 RAG 결과가 수식으로 confidence를 자동 보정하는 것은 아니다. prompt 안에서 "이런 경우 confidence를 높이거나 낮추라"고 지시하고, 최종 판단은 LLM expert가 내린다. 따라서 RAG는 **결정 규칙**이 아니라 **과거 사례 기반의 판단 보조 근거**에 가깝다.

## 8. 성과 및 백테스트 결과

한국형 MERA는 종목 추천에서 끝나지 않고 실제 수익률을 계산한다. 원작자 종목평가 흐름도 기준으로 평가 과정은 다음과 같다.

```text
평가 대상 선정
→ 실제 수익률 계산
→ AI 투자 판단 검토
→ 성과 지표 계산
→ 결과 기록 저장
```

평가 방식은 월별과 주별로 나뉜다. 월별은 월초에 선정한 포트폴리오를 월말에 평가하고, 주별은 월요일 선정 후 5영업일 뒤 평가하는 방식이다.

평가 대상은 전문가별 포트폴리오와 통합 포트폴리오다. 각 expert가 최대 5개 종목을 고르고, Aggregator(추천 결과 통합기)가 통합 포트폴리오 Top-5를 만든다. 따라서 전문 관점별 성과와 통합 포트폴리오 성과를 비교할 수 있다.

원작자 종목평가 흐름도 기준으로 평가 대상은 전문가별 포트폴리오 5개씩 5명, 그리고 통합 포트폴리오 5개다. 따라서 한 번의 평가에서 최대 30개 종목이 검토될 수 있다. 평가는 단순히 수익이 났는지만 보는 것이 아니라, AI 판단이 적절했는지, 실패 원인은 무엇인지, 다음 번 판단에서 개선할 점은 무엇인지까지 기록하는 구조다.

현재 리포트 파일 기준으로 통합 포트폴리오는 2025 월별 요약에서 평균 수익률 약 +5.0%, 적중률 약 63%, 2026 월별 요약에서 평균 수익률 약 +7.1%, 적중률 약 58%로 정리되어 있다. 2026 주별 요약에서는 평균 수익률 약 +1.2%, 적중률 약 62%다.

다만 이 수치는 실전 투자 성과로 바로 일반화하기 어렵다. 거래비용, 슬리피지(주문 가격과 실제 체결 가격의 차이), 리밸런싱 기준, benchmark(비교 기준) 대비 초과성과, 데이터 누락 여부가 추가로 검증되어야 한다. 현재 결과의 의미는 "수익을 보장하는 전략"이 아니라, 한국형 MERA가 생성한 포트폴리오를 실제 수익률 기준으로 평가할 수 있는 구조를 갖추었다는 데 있다.

## 9. 결론 및 향후 과제

한국형 MERA의 결론은 세 문장으로 정리할 수 있다.

첫째, 원본 MERA는 다양한 주식 패턴을 다루기 위해 Retrieval과 MoE(Mixture of Experts, 여러 전문가 조합)를 결합한 딥러닝 예측 모델이다.

둘째, 한국형 MERA는 이 아이디어를 한국 주식시장 데이터, 과거 유사패턴 RAG, LLM 전문가, Aggregator(추천 결과 통합기), 백테스트로 구성된 설명 가능한 투자 분석 시스템으로 바꿨다.

셋째, 이 구현체의 가치는 단순히 "종목을 추천한다"가 아니라, 과거 사례와 전문가 관점, 최종 포트폴리오 구성, 실제 수익률 평가를 하나의 흐름으로 연결했다는 점이다.

향후 과제는 명확하다. RAG 검색 품질을 정량적으로 검증해야 하고, LLM 판단의 일관성을 관리해야 하며, 거래비용과 benchmark(비교 기준) 비교를 포함한 더 엄격한 성과 검증이 필요하다. 또한 KOSDAQ150이나 중소형주로 확장할 경우 데이터 품질과 급격한 테마 변동, 거래정지/상장폐지 처리도 함께 보강해야 한다.

핵심 결론은 다음과 같다.

> 한국형 MERA는 논문 MERA를 그대로 복제한 모델이 아니라, 논문의 Retrieval + MoE 아이디어를 한국 시장에서 설명 가능한 LLM 투자 분석 파이프라인으로 바꾼 사례다.

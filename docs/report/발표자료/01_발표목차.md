## 슬라이드별 명세

### 표지/목차
- **S1. 표지** — 제목 "한국형 MERA — 다양한 한국 주식 패턴 분석을 위한 검색 증강(RAG) 기반 LLM 전문가 혼합 시스템" (논문 원제에서 차용). 부제로 재해석 한 줄 + 원논문 출처 명기.
- **S2. 목차** — 5개 섹션. "이론적 토대 → 비교/어필 → 구현 → 결과" 흐름 강조.

### 01. Introduction
- **S3. 한 줄 요약 + WHAT/WHY/HOW** — LLM 에이전트 5명이 KOSPI200을 매달 분석해 포트폴리오 자동구성 + 실수익 검증. 백테스트란?/왜 흥미로운가?/어떻게 동작하나?

### 02. 원본 MERA 논문
- **S4. 원본 논문 소개** — "MERA: Mixture-of-Experts with Retrieval-Augmented Representation" (류유준 외, 칭화대·E Fund·선전대). 핵심 기여 3가지: 차별화 모델링 / 검색증강 표현 / 플러그인 모듈.
- **S5. 왜 새 모델이 필요한가** — Single-branch 한계(모든 종목 동일 파라미터 → 섹터별 정반대 흐름 상쇄, 예: COVID 초기) vs MoE(패턴별 전문가 분리 + GateNet 라우팅).
- **S6. MERA 핵심 아이디어 3가지** — ① 자기지도 사전학습(Masked AE) ② 검색증강 표현(유사 과거 Top-N 라벨) ③ 희소 전문가 혼합(GateNet Top-1 + Attention-GRU).

### 03. 논문 → K-MERA 재해석 (비교)
- **S7. 1:1 매핑 비교표** — 전문가 실체 / 구성 / 라우팅 / 검색증강 / 주기 / 집계 / 성과지표를 논문(DL) vs 우리(LLM) 두 열로 대비.
- **S8. 구조적 차이** — 단일 end-to-end 딥러닝 모델(내부 계산 중심) vs 모듈형 LLM 파이프라인(의사결정 흐름 중심). "복제가 아니라 아이디어의 재해석".

### 04. 무엇이 좋아졌나 / 유의미한 시도 (어필)
- **S9. 우리가 바꾼 것 & 더 나아진 점** — ① 설명 가능성(왜 BUY인지 근거·리스크 출력) ② 한국 시장 특화(DART 공시·KRX 공매도·네이버 fallback) ③ 단순 예측 → 포트폴리오·실수익 백테스트로 확장 ④ LLM을 자유대화가 아닌 구조화 모듈(JSON)로 사용.
- **S10. 유의미한 시도인 이유 + 정직한 프레이밍** — "원본보다 성능이 좋다"가 아니라 "학술 아이디어를 한국 시장에서 설명 가능·실무 적용 가능한 형태로 재해석". 신뢰도의 의미가 다름(예측정확도 vs 설명가능성). 수업에서 배운 개념(Multi-Agent, LangGraph fan-out, 앙상블=신뢰도 가중)의 실전 적용.

### 05. System Design — 4단계 파이프라인
- **S11. 전체 아키텍처** — 4단계 개요(스크리너→전문가→어그리게이터→평가) + 설계원칙(전처리로 LLM 호출 압축 / fan-out 병렬 / 투명성).
- **S12. 1단계 스크리너** — Rule-based로 KOSPI200 → 전문가별 Top-15 후보 압축. 휴리스틱 점수 예시(성장·가치·위기).
- **S13. 2단계 RAG** — 패턴 텍스트 → 임베딩(1,536차원) → ChromaDB 코사인 유사도 Top-5 → 과거 실수익(label)로 confidence 조정. (이게 논문 'Retrieval'의 우리 버전)
- **S14. 3단계 5 전문가 에이전트** — 같은 LLM(Claude Sonnet 4.6)에 5개 페르소나(성장·가치·테마·배당·위기) 부여. JSON 출력(signal/confidence/target_return/risks/reason).
- **S15. 4단계 어그리게이터 & 평가** — 신뢰도 가중 통합(confidence≥0.60, Top-20) + 평가지표(적중률·ARR·MDD·Sortino·Calmar).

### 06. Results
- **S16. 백테스트 성과** — 2025(12개월): 통합 +76.4%, 성장주 +78.6%, Sortino 25.36, 적중률 83%. / 2026(5개월): 위기종목 +58.1%, 성장주 +53.6%, 통합 MDD -12.8%, Sortino 9.22.
- **S17. 실시간 대시보드 & 실제 포트폴리오** — Streamlit 대시보드 구성 + 2026-05-19 실제 추천 예시(씨젠·와이지원·삼성전자 등).

### 07. Conclusion
- **S18. 기여 요약 & 강조 포인트** — 재해석(방법론)·엔지니어링(엔드투엔드)·검증(재현 가능 백테스트). AI 전공자 관점 강조 5포인트.
- **S19. 한계 & 향후 과제** — 백테스트 기간 제한·LLM 비결정성·거래비용 미반영·confidence 캘리브레이션 / 향후: 기간 확대·비용 반영·코스닥 확장·RA 모듈 본격화.
